# Expense Tracker - By Cashley
A simple expense tracker console app I made in C# to practice OOP, file handling and LINQ
## Features
- Add expenses with reason and amount
- Automatically categorizes impact (Low / Medium / High)
- Remove expenses by index
- Persistent storage using a text file
- Displays all expenses in a clean format
- Calculates total expenses
## Concepts practiced
- Object-Oriented Programming (OOP)
- Separation of Concerns (Services, Data, Parsing, Models)
- File I/O in C#
- LINQ (Select, Sum)
- Input validation and error handling
## How to run
> dotnet run
